# large_sample — 5 万企业 / 两年 / 带单位 的重新抽样

本文件夹是在原 `productivity\` 管线基础上**重新拉样本**的独立版本，不改动原文件。

## 与上一版的三处差异

| 维度 | 上一版（productivity） | 本版（large_sample） |
|---|---|---|
| 样本量 | ~3,410 家 | **50,000 家** |
| 年份 | 仅 2017 | **2017 + 2018**（带 `year` 维度） |
| 单位 | SQL 聚合时忽略单位 | **聚合时带上 `单位`**，留待后期 harmonize |

## 样本口径（已与你确认）

- **抽样框**：从"**两年（2017、2018）都既是买方又是卖方**"的企业池里抽。
  - 即 `2017既买又卖 ∩ 2018既买又卖`（每年内都要求买方∩卖方）。
  - 这样保证两年都有观测、且两年都具备外包识别前提（既买又卖）。
- **抽样方法**：从企业池中按 `HASHBYTES('MD5', cid)` 排序取前 50,000——**确定性随机**（同一池子结果可复现），落成固定表 `dbo.tmp_sample_cid2`。
- **只建一次**：生成后不要重跑，保证后续 5 张聚合查询口径一致。

## 数据源

| 年份 | 三段式表名 |
|---|---|
| 2017 | `GX17.dbo.GX1701` / `GX1702` / `GX1703` |
| 2018 上半年 | `GX.dbo.gaoxiao1801` |
| 2018 下半年 | `GX02.dbo.GX02` |

两年表结构一致，列：`购方企业ID / 购方地区 / 销方企业ID / 销方地区 / 项目代码 / 项目 / 开票金额 / 单位 / 数量 / 单价 / 税额`。

## 运行顺序

> SQL 存成 `.txt`，方便直接复制进 Navicat 新建 query 运行。

1. **`00_build_sample.txt`** — 整段复制运行，构建企业池并抽 50,000 家 → `dbo.tmp_sample_cid2`。
   先看打印的 `pool_size`（企业池大小）；若不足 5 万再回来商量放宽口径。**本步只在服务器建表，无需导出。**
2. **`01_extract_aggregates.txt`** — 5 张聚合查询，**每张单独复制运行，跑完手动 export 成对应 CSV**：
   | 查询 | 导出文件名 | 颗粒度 |
   |---|---|---|
   | 表1 | `firm_buy.csv` | 购方企业ID × 项目代码 × 单位 × year |
   | 表2 | `firm_sell.csv` | 销方企业ID × 项目代码 × 单位 × year |
   | 表3 | `city_buy.csv` | 购方地区 × 项目代码 × 单位 × year（全量） |
   | 表4 | `city_sell.csv` | 销方地区 × 项目代码 × 单位 × year（全量） |
   | 表5 | `firm_city.csv` | 企业ID × year × 地区（买方侧，带出现次数 cnt） |

## 运行注意

- Navicat 中用**英文半角输入法**，避免全角字符报错。
- 需要对 `GX17`、`GX`、`GX02` 三个库都有读权限（跨库 UNION）。
- 金额用 `SUM(开票金额)`，正负红冲自动对冲为净额（净值 ≤ 0 的留给 Python drop）。
- 数量用 `SUM(TRY_CAST(数量 AS float))`，乱码自动变 NULL 不影响 SUM。
- `项目代码` 不在 SQL 清洗，Python 端处理（右补零 19 位 → 取前 9 位 → 匹配 bianma）。
- 这些查询要扫两年共数十亿行，**耗时较长**，建议挂着跑。

## 单位带来的下游影响（待 01_clean 改写时处理）

- 现在颗粒度多了 `单位`：同一 (企业, 产品) 可能有多行（kg / 吨 / 箱…），NULL 单位单独成一类。
- **单价、leave-one-out 都要在同一单位内计算**，否则又把不同单位混一起。
- **外包识别**（fb ∩ fs）建议仍在 (企业, 产品) 层面、**忽略单位**（买 kg、卖件也算外包）；只有价格/数量才按单位算。
- `city_buy/city_sell` 的 `买方企业数/卖方企业数`是按 (地区,产品,**单位**,年) 计数（per-unit）；做市场厚度变量时如何跨单位合并，留到 harmonize 阶段一并决定。
- 两年面板下，企业层变量（ln_Output、ln_K）随年份变化，**不再与 Firm FE 完全共线**，加 Firm FE 也能识别——比上一版只能看 OLS 更好。
